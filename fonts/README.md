# Fonts

Self-hosted so the site makes no requests to other servers. All three families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows using and redistributing them with a website.

- Archivo by Omnibus-Type: headings
- IBM Plex Sans by IBM: body text, navigation and buttons
- IBM Plex Mono by IBM: specs, dates, table labels and figure labels

Files are the Latin and Latin Extended subsets in WOFF2, downloaded from Google Fonts.
